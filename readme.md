# Uniconta Tile Demo Plugin

This repository contains a sample Uniconta plugin demonstrating how to create a **custom Tile Type** and **Tile Visualization**.

The project serves as a starting point for developers who want to extend Uniconta's tile functionality with their own data sources and visualizations.

## What's Included

- **Custom Tile Type** – Example implementation of a tile type.
- **Custom Tile Visualization** – WPF-based visualization using XAML.
- **Data Providers** – Examples of retrieving and supplying data to tiles.
- **Warehouse Example** – Sample implementation displaying warehouse status and summary information.

## Getting Started

1. Open `Plugin.Uniconta.TileDemo.slnx` in Visual Studio.
2. Build the project.
3. Load the compiled plugin into Uniconta.
4. Use the example implementations as a reference for building your own tiles.

## Purpose

This project is intended for **demonstration and educational purposes**, showing how developers can extend the Uniconta tile framework with custom functionality.
